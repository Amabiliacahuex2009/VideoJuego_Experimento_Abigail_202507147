# Fase 1: Analisis 
El Experimento Abigail es un juego de terror y supervivencia en primera persona dirigido a un público de 13 a 15 años. La experiencia se desarrolla en un laboratorio abandonado en donde el jugador o los jugadores deben escapar mientras exploran habitaciones, buscan llaves, herramientas, recursos para sobrevivir, la tensión aumenta cuando se encuentran con el monstruo que deambula por los pasillos.
# Fase 2: Diagrama de flujo
En este diagrama se ve el esquema del analisis del juego, en donde estan los pasos que se deben seguir para poder jugar, como el flujo de bienvenida, ingreso del nombre y elección del personaje, las opciones para elegir entre Solitario o Multijugador y sus dificultades, la secuencia paso a paso para explorar el laboratorio, juntar suministros, buscar llaves y reaccionar si aparece el monstruo (esconderse) y la evaluación que determina si el jugador encuentra la salida para ganar o debe seguir buscando.    
# Fase 3: Codigo
